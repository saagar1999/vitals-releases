# Vitals

A Mac app for keeping an eye on your Mac and cleaning it safely, by Saagar Sutaria.

## Download

**[Download the latest version](https://github.com/saagar1999/vitals-releases/releases/latest)**: open the `.dmg` and drag Vitals into Applications.

Requires an Apple Silicon Mac running macOS 26 or later.

The first time you open it, macOS may say it "could not verify" Vitals, because it isn't distributed through the App Store. Go to **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to Vitals. You only need to do this once.

## Updates

Vitals checks for updates once a day and offers to install them. You can also choose **Vitals → Check for Updates…** at any time.

## Acknowledgements

Vitals includes [Mole](https://github.com/tw93/mole) by tw93 (GPL-3.0) for cleaning and system readings, and [Sparkle](https://sparkle-project.org) for updates.
